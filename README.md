# 🚀 Irden Launcher

Официальный лаунчер для игры Starbound с автоматической синхронизацией модов и обновлений.

## 📥 Установка

1. Скачайте последнюю версию из раздела [Releases](../../releases)
2. Запустите установочный файл `.msi`
3. Следуйте инструкциям установщика

## ✨ Возможности

- 🎮 **Быстрый запуск игры** - запускайте Starbound одним кликом
- 🔄 **Автоматическая синхронизация модов** - все необходимые моды загружаются и обновляются автоматически
- 📦 **Проверка обновлений OpenStarbound** - лаунчер отслеживает актуальность установленной версии
- 🔍 **Автопоиск игры** - автоматическое определение пути к установленной игре
- ⚙️ **Простая настройка** - интуитивно понятный интерфейс
- 🆙 **Самообновление** - лаунчер автоматически проверяет наличие новых версий

## 🖥️ Системные требования

- **ОС:** Windows 10 или выше
- **Место на диске:** ~10 МБ для лаунчера + место для модов
- **Интернет:** Требуется для загрузки модов и проверки обновлений

## 🎯 Как использовать

### Первый запуск

1. При первом запуске лаунчер попытается автоматически найти установленную игру Starbound
2. Если путь найден, выберите его из списка или укажите путь вручную
3. После выбора пути автоматически начнётся загрузка необходимых модов
4. Дождитесь завершения синхронизации модов

### Обычное использование

1. Запустите лаунчер
2. Дождитесь проверки обновлений и синхронизации модов
3. Нажмите кнопку **"🎮 Играть"** для запуска игры

### Смена пути к игре

Если вам нужно изменить путь к игре:
1. Нажмите кнопку **🔄** в правом верхнем углу
2. Выберите новую папку с игрой

## 🔧 Устранение неполадок

### Лаунчер не находит игру автоматически

- Убедитесь, что игра установлена через Steam
- Попробуйте указать путь к игре вручную (обычно: `C:\Program Files (x86)\Steam\steamapps\common\Starbound`)

### Ошибка при синхронизации модов

- Проверьте подключение к интернету
- Нажмите кнопку **"Повторить синхронизацию модов"**
- Убедитесь, что у вас есть права на запись в папку с игрой

### Игра не запускается

- Проверьте правильность указанного пути к игре
- Убедитесь, что игра установлена корректно
- Попробуйте запустить игру напрямую из Steam для проверки

## 📝 Примечания

- Лаунчер требует подключения к интернету для загрузки модов и проверки обновлений
- При первом запуске может потребоваться время на загрузку всех модов
- Все моды загружаются в папку `profiles/irden/mods` внутри каталога игры
